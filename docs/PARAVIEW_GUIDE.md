# ParaView Visualization Guide

This guide shows how to create publication-quality plots from SU2 VTU files using ParaView. Most visualizations should come from ParaView, not matplotlib.

## Setup

1. Open ParaView
2. File -> Open -> select `output/euler/flow.vtu` (or `output/rans/flow.vtu`)
3. In Properties panel, click Apply
4. The domain shows the top half of the axisymmetric nozzle (bottom is axis of symmetry)

## Plot 1: Mach Number Contour

This is the primary visualization showing the full flow field.

### Steps
1. With the VTU loaded, go to **Coloring** dropdown (toolbar) -> select **Mach**
2. Click **Rescale to Data Range** (toolbar icon) or **Edit Color Mapping** (next to color bar)
3. Set colormap: **Jet** (or **Turbo** for better perceptual uniformity)
4. **Adjust range**: Click "Rescale" and set Range 0 to Range 1 as 0 to 5
5. **Add nozzle wall overlay**:
   - File -> Open -> load `output/euler/nozzle.su2` (mesh file)
   - In Properties, go to **Representation** -> select **Wireframe**
   - Set Color to black, Line Width = 3
   - This shows the nozzle wall as a black wireframe over the Mach contour

### Export
1. File -> Save Screenshot
2. Resolution: 1920 x 640 (wide format for nozzle)
3. Filename: `docs/assets/images/mach_contour_paraview.png`

---

## Plot 2: Pressure Contour

Shows static pressure distribution through the nozzle.

### Steps
1. Coloring -> select **Pressure**
2. Colormap: **Cool-Warm** (blue for low pressure, red for high pressure)
3. Range: Rescale to automatic, or manually set 0 to 1e7 Pa
4. Add nozzle wireframe (same as Mach contour)

### Export
1. Save Screenshot -> `docs/assets/images/pressure_contour_paraview.png`

---

## Plot 3: Shock Diamonds (Density Gradient)

Visualizes compressibility effects in the plume.

### Steps
1. Coloring -> select **Density**
2. Apply **Gradient Of Unstructured Data** filter:
   - Sources -> Alphabetical -> Gradient Of Unstructured Data
   - Select the VTU as Input
   - Set **Scalar Array** = Density, **Gradient Type** = Gradient
   - Click Apply
3. Coloring on the gradient output -> select **gradient_mag** (magnitude)
4. Colormap: **Hot** or **Inferno**
5. Range: 0 to 99th percentile of gradient magnitude

### Export
1. Save Screenshot -> `docs/assets/images/shock_diamonds_paraview.png`

---

## Plot 4: Mach vs Pressure (XY Plot)

Shows the relationship between Mach number and static pressure along the centerline.

### Steps
1. Select the VTU in the Pipeline Browser
2. **Filters -> Alphabetical -> Plot Over Line**
3. In Properties:
   - Set **Point 1**: (x_start, 0, 0) -- nozzle inlet on axis
   - Set **Point 2**: (x_end, 0, 0) -- nozzle exit on axis
   - **Resolution**: 500 points
   - Click Apply
4. In the **PlotView** that appears:
   - Left Y-axis: Mach Number
   - Right Y-axis: Pressure
   - Use **Edit Series** to show both variables

### Export
1. File -> Save Data -> CSV format
2. Or: File -> Save Screenshot for visual

---

## Plot 5: Wall Pressure Distribution

Shows pressure along the nozzle wall (not centerline).

### Steps
1. Select the VTU in Pipeline Browser
2. **Filters -> Alphabetical -> Extract Surface**
3. Apply
4. **Filters -> Alphabetical -> Plot Selection Over Time** (or use Python trace)
5. Alternative: Use Python console to extract wall points (see Appendix)

### Export
1. Save Screenshot -> `docs/assets/images/wall_pressure_paraview.png`

---

## Plot 6: Euler vs RANS Comparison

Side-by-side Mach contours for inviscid vs viscous simulation.

### Steps
1. Open both VTU files (Euler and RANS)
2. Window -> Tile Cards Horizontally (or use View -> Split View)
3. Set both views to Mach coloring with same range
4. Add nozzle wireframe to both
5. Use **Annotations** to label "Euler" and "RANS SST"

### Export
1. Save Screenshot -> `docs/assets/images/mach_comparison_paraview.png`

## Quick Reference: ParaView Filters

| Filter | Location | Purpose |
|--------|----------|---------|
| **Plot Over Line** | Filters -> Alphabetical | Extract 1D data along a line |
| **Extract Surface** | Filters -> Alphabetical | Get surface from volume mesh |
| **Gradient Of Unstructured Data** | Filters -> Alphabetical | Compute spatial gradients |
| **Glyph** | Filters -> Alphabetical | Visualize vectors as arrows |
| **Contour** | Filters -> Alphabetical | Extract iso-surfaces |
| **Slice** | Filters -> Alphabetical | Cut through 3D domain |
| **Threshold** | Filters -> Alphabetical | Filter by value range |

## Appendix: Python Script for Wall Pressure Extraction

```python
"""Extract wall pressure from VTU file."""
import sys
sys.path.insert(0, 'src')
from cfd.vtu_parser import parse_vtu
from nozzle.geometry import generate_contour
from nozzle.config import NozzleConfig
import numpy as np

config = NozzleConfig(throat_radius=0.05, expansion_ratio=16.0)
x_wall, y_wall = generate_contour(config)

data = parse_vtu('output/euler/flow.vtu')
coords = data.coordinates

# For each wall point, find nearest VTU node and extract pressure
wall_pressure = []
for i, (xw, yw) in enumerate(zip(x_wall, y_wall)):
    dist = np.sqrt((coords[:, 0] - xw)**2 + (coords[:, 1] - yw)**2)
    nearest = np.argmin(dist)
    if data.pressure is not None:
        wall_pressure.append(data.pressure[nearest])
    else:
        wall_pressure.append(0.0)

# Plot
import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(10, 6))
ax.semilogy(x_wall * 1000, np.array(wall_pressure) / 1e6, 'b-', linewidth=2)
ax.set_xlabel('Axial Distance (mm)')
ax.set_ylabel('Static Pressure (MPa)')
ax.set_title('Wall Pressure Distribution')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('docs/assets/images/wall_pressure.png', dpi=150)
plt.close()
```
