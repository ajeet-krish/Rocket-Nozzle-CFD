Rocket Nozzle CFD: Compressible Flow Analysis

How does a rocket engine convert high-pressure combustion gases into thrust? The answer lies in the converging-diverging (de Laval) nozzle, a geometry that accelerates flow from subsonic to supersonic speeds. Understanding compressible flow through nozzles is fundamental to propulsion engineering.

This project simulates rocket nozzle flow using SU2 compressible CFD, validated against three independent methods: isentropic analytical relations, Method of Characteristics, and grid convergence study. The pipeline sweeps expansion ratio, chamber pressure, and throat radius to build an aerodynamic database.

Pipeline Walkthrough

Nozzle Geometry

Generate a parametric Rao parabolic bell nozzle contour using a quadratic Bezier curve. The 80% length bell with 30-degree throat half-angle is the industry standard for optimal thrust. Expansion ratio epsilon=12 produces exit Mach 4.13 for air.

Structured O-Grid Mesh

Generate a structured O-grid mesh using Gmsh transfinite meshing. The mesh is split into 4 zones (converging, throat, diverging, plume) with boundary layer refinement. First cell height 1e-6m achieves y+ less than 1 for RANS compatibility.

■
Mesh visualization (run Phase 2 to generate)

SU2 Euler Solver

Run SU2 compressible Euler simulation with ROE flux scheme, MUSCL reconstruction, and axisymmetric flag. Chamber pressure 10 MPa, temperature 3500K, exit at 1 atm. Converges in approximately 2000 iterations.

RANS SST k-omega

Add viscous effects with Reynolds-Averaged Navier-Stokes equations and SST k-omega turbulence model. Low-Re wall treatment captures boundary layer development. Adiabatic wall boundary conditions.

Post-Processing & Validation

Extract flow properties from VTU solution files. Compute wall pressure distribution, density gradient for shock diamond visualization, and thrust coefficient. Triple validation: isentropic vs MoC vs SU2.
