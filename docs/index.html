Rocket Nozzle CFD: Compressible Flow Analysis

How does a rocket engine convert high-pressure combustion gases into thrust? The answer lies in the converging-diverging (de Laval) nozzle, a geometry that accelerates flow from subsonic to supersonic speeds. Understanding compressible flow through nozzles is fundamental to propulsion engineering.

This project simulates rocket nozzle flow using SU2 compressible CFD, validated against three independent methods: isentropic analytical relations, Method of Characteristics, and grid convergence study. The pipeline sweeps expansion ratio, chamber pressure, and throat radius to build an aerodynamic database.

Pipeline Walkthrough

Nozzle Geometry

Generate a parametric Rao parabolic bell nozzle contour using a quadratic Bezier curve. The 80% length bell with 30-degree throat half-angle is the industry standard for optimal thrust. Expansion ratio epsilon=16 produces exit Mach 4.46 for air.

SU2 Euler Solver

Run SU2 compressible Euler simulation with ROE flux scheme and axisymmetric flag. Chamber pressure 9.7 MPa, temperature 3600K, exit at 1 atm. Converges in approximately 349 iterations with exit Mach 4.49.

Euler vs RANS: Mach Number

The primary difference between inviscid (Euler) and viscous (RANS) simulations appears in the Mach number distribution. Euler reaches M=4.49 at exit, while RANS reduces this to M=4.10 due to boundary layer displacement. This 8.7% difference is consistent with viscous nozzle theory.

Post-Processing & Validation

Extract flow properties from VTU solution files. Compute wall pressure distribution, density gradient for shock diamond visualization, and triple validation against isentropic theory and Method of Characteristics. Max error: 0.75%.
